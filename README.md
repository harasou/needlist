# needlist

シンプルな NEED / HAVE 管理アプリ。買い物リスト・持ち物リストなど、何でも使えます。

**https://harasou.github.io/needlist/**

## 機能

- 複数リストをタブで管理
- アイテムを NEED / HAVE の 2 状態で管理
- タップで状態を切り替え（3 秒以内なら取り消し可能）
- 複数アイテムをまとめて切り替え
- アイテム名の昇順で自動ソート
- PWA 対応（ホーム画面に追加してアプリとして利用可能）
- オフライン動作

## インストール（Android / iOS）

1. Chrome / Safari でサイトを開く
2. 「ホーム画面に追加」を選択
3. ネイティブアプリ風に起動します
